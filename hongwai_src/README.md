# 红外收发器 (IR Transceiver)

基于 FPGA 的红外（IR）数据收发系统，使用 VHDL 实现。

## 项目概述

本项目实现了一个红外数据传输系统，包含发送端和接收端两部分，支持 8 位数据的无线传输。

- **发送模块 (ir_tx)**：通过 38kHz 载波调制红外信号，支持按键触发发送
- **接收模块 (ir_rx)**：解调红外信号并还原为 8 位数据，具备自发送屏蔽功能

## 技术规格

| 项目 | 规格 |
|------|------|
| FPGA 芯片 | Cyclone IV E (EP4CE6F17C8) |
| 开发工具 | Quartus Prime 18.1.0 Lite |
| 时钟频率 | 50 MHz |
| 载波频率 | 38 kHz |
| 数据位宽 | 8 bit |
| 调制方式 | 载波 ON-OFF 键控 (OOK) |

## 模块说明

### ir_tx - 红外发送模块

发送模块负责将 8 位数据通过红外光发送出去，主要特性：

- **38kHz 载波生成**：由 50MHz 时钟分频产生
- **按键触发**：按键按下时启动数据发送
- **帧格式**：起始位 + 8 位数据（LSB 优先）+ 停止位 + 空闲期
- **自发送指示**：`tx_active` 信号通知接收模块进行屏蔽

| 端口 | 方向 | 说明 |
|------|------|------|
| clk | in | 系统时钟 (50MHz) |
| key | in | 按键输入（低电平有效） |
| data_in[7:0] | in | 待发送的 8 位数据 |
| ir_out | out | 红外载波输出 |
| tx_active | out | 发送活动信号（用于接收屏蔽） |

### ir_rx - 红外接收模块

接收模块解调红外信号并恢复数据，主要特性：

- **边沿检测**：检测红外信号的起始边沿
- **同步采样**：在 38kHz 载波周期中点进行采样
- **自发送屏蔽**：发送期间自动屏蔽接收，防止自干扰
- **状态机**：IDLE → WAIT_START → SAMPLE_DATA

| 端口 | 方向 | 说明 |
|------|------|------|
| clk | in | 系统时钟 (50MHz) |
| ir_in | in | 红外信号输入 |
| tx_active | in | 发送活动信号（屏蔽用） |
| data_out[7:0] | out | 接收到的 8 位数据 |

## 引脚分配

### 发送相关
| 信号 | 引脚 |
|------|------|
| CLK50MHZ | E1 |
| key | J14 |
| ir_out (OUTPUT) | C16 |
| tx_active | L14 |
| TX_DATA[7:0] | N13, N14, M12, N16, N15, P16, P15, R16 |

### 接收相关
| 信号 | 引脚 |
|------|------|
| ir_in (IR_IN) | T14 |
| DATA_OUT[7:0] | C3, A2, B3, A3, B4, A4, B5, A5 |

## 使用方法

1. 使用 Quartus Prime 18.1.0 Lite 打开 `hongwai.qpf` 工程
2. 编译工程并检查时序约束
3. 连接红外发射/接收模块到对应引脚
4. 通过按键触发数据发送
5. 接收端将解调数据输出到 DATA_OUT 引脚
